# Amanulla Fathima Amna — QA Portfolio

A dark, recruiter-focused portfolio for an aspiring Quality Assurance Engineer.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Deploy

Import this repository into Vercel or Netlify. The site is a standard Next.js app.

## Before publishing

- Replace `/public/amna.jpg` only if you want a newer professional photo.
- Add a resume PDF if you want the Resume CTA enabled.
- Add public links for the Postman collection or other projects when available.
- Set the canonical URL and Open Graph image when your domain is known.
- Test GitHub, LinkedIn and email links.
- Run a Lighthouse check on mobile and desktop.
